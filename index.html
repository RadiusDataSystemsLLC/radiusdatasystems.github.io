About Us

Radius Data Systems specializes in data collection and analysis using Microsoft and open source technologies. Our data-based services include intelligent data collection by easily defined data profiles, multi-source data merge, pattern and relationship discovery, natural language processing, and other techniques to clean and build comprehensive data sets for your application's consumption.

We have several data services readily available, and the expertise to integrate with existing applications or build entirely new ones rapidly and effectively. We also build unique prototypes from the insights our data analysis infrastructure can produce, demoed to select audiences.

Consulting & Services

  • Intelligent Data Collection driven by reusable data profiles
  • Multi-Source Data Merge, Pattern & Relationship Discovery, and Natural Language Processing (NLP)
  • Enterprise Application Integration and Custom Software Engineering on Microsoft and Open-Source Stacks

LiNK Technology Infrastructure

  • LiNK — Cross-platform modular technological infrastructure built for rapid development without monolithic framework overhead.
  • LiNK Distributed Network — Data-document and metadata-driven distributed processing infrastructure for large-scale data processing, AI, and analytics.
  • BlockLiNK — Integration-first blockchain foundation supporting over 20 blockchain technologies for public and private implementations.
  • LiNK Simple Services — Modular web and service host controllers with processing modules for enterprise integration, NLP, image analytics, chatbots, and AI.
  • LiNK UI — Lightweight TypeScript UI framework modeled after C# and Java conventions.
  • LiNK Core — Generalized tools for email, tracing, messaging, networking, and data acquisition, identification, validation, and delivery.
